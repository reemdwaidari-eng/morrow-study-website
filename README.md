# Morrow Storefront — Version 1

A responsive, multi-page storefront prototype for the Morrow digital lifestyle brand.

## Pages
- `index.html` — homepage
- `shop.html` — product catalog and category filters
- `product.html` — Student Planner product details
- `about.html` — brand story
- `contact.html` — demo contact form
- `faq.html` — frequently asked questions

## Run locally
No build tools or installation are required.
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local server (recommended), open a terminal in this folder and run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Included interactions
- Responsive mobile navigation
- Shop category filters
- Demo shopping bag saved in browser local storage
- Remove items and clear demo bag
- Demo contact/newsletter form confirmation

## Not connected yet
- Real payment processing
- Customer accounts or order database
- Secure digital file delivery
- Live contact form/email service
- Legal pages and final business policies

This is a visual and functional frontend prototype only. Do not accept real orders or collect customer information through it yet. Before commercial launch, involve a parent/guardian and confirm applicable Saudi requirements, payment provider age rules, privacy terms, product licensing and consumer policies.

## Customization
- Edit colors, fonts and layout in `styles.css`.
- Edit product names, prices and descriptions in `shop.html` and `product.html`.
- Replace the demo photography URLs with images you own or have permission to use before launch.
- The current image links require an internet connection.
